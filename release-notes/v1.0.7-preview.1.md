# LocalFirst-AI 1.0.7 Preview 1

This update improves MCP connections and everyday chat clarity.

## Features and improvements

- **MCP sign-in:** added browser sign-in for compatible remote servers on Windows and Android.
- **Message deletion:** fixed deleted messages still being included when continuing a chat.
- **Mobile usage:** tap an assistant message's usage count to see its full breakdown.
- **Sent context:** messages now show the requested Skills and **Ask about this** excerpts included with them.
- **Image previews:** buttons and colours now match LocalFirst-AI's light and dark themes.

## Platforms

- **Windows x64:** the primary desktop experience, with installer and portable options.
- **Android:** an early sideloaded preview for Android 7.0+ arm64-v8a devices and x86_64 emulators, with more limited tooling. Local models need a reachable model server.
- Public Web, macOS and iOS packages are not included.

## Important notes

- **Back up important data before upgrading.** Preview versions may change settings or data formats. Restore replaces the backup's covered data rather than merging it; secure credentials may need to be re-entered.
- **Local HTTPS certificate trust is optional and off by default.** Prefer a trusted certificate authority. Enable the local-certificate option only for a server you control; it weakens server authentication and can expose prompts and API keys to interception. Certificates must still match the endpoint and be valid. Changing the HTTPS host or port requires a new opt-in.
- **Live updates are text-only.** To send Skills, selected text or files, wait for the response to finish or stop it first.
- **Supervisor delegation is opt-in.** Review team limits and give specialists separate responsibilities. Work can continue while you navigate within the running app, but closing LocalFirst-AI or mobile suspension can interrupt it. Unfinished assignments do not restart automatically.
- **Stop does not undo completed actions.** Check saved results and uncertain external actions before retrying interrupted work. Wait for work to finish closing before reusing a workspace, changing its settings or retrying a blocked deletion.
- **File tools have full access by default within operating-system permissions.** Optional directory-access requests do not grant administrator privileges or sandbox processes, plugins or integrations. Review access before using sensitive files. See [Tools and access](../docs/workspaces-and-tools.md).
- **Review Skills before use or sharing.** Import guidance from trusted sources and remove confidential project details from workflow drafts. Skills provide written guidance, not permissions; bundled scripts are not run.

## Known limitations

This is preview software, not a guarantee of production readiness or unattended safety. Review important output and consequential actions.

- Model, provider, device and tool support vary. A successful connection does not guarantee reliable work with every tool or large request.
- MCP browser sign-in requires a compatible server, a registered client and the necessary account permissions.
- Some websites require sign-in or restrict automated access. On Windows, pages that need browser rendering require installed Edge or Chrome; Android web retrieval is more limited.
- Live response updates require a supported connection. Files, Skills and selected-text context remain next-message inputs.
- Windows and Android do not offer identical tool coverage. Mobile suspension or closing the app can interrupt work and downloads.
- System voice input needs microphone permission and an available device speech service. The system service may use online recognition.
- Large documents, media and slower storage can still take time to prepare.

See the [full preview scope](../PREVIEW.md) and [Troubleshooting](../docs/troubleshooting.md).
