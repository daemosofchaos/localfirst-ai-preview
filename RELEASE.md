# LocalFirst-AI V1.0

**Your AI assistants. Your workspace. Local first.**

LocalFirst-AI is a practical workspace for working with AI—not just chatting with it. Bring a hosted or compatible local model, give an assistant a clear objective and keep its conversation, notes, tasks, source material and deliverables together.

## A workspace built around the outcome

Use Rooms for assistant roles and workspaces for individual projects. Save decisions as notes, track next steps as tasks and keep generated artifacts with the conversation. Search previous discussions and return to the relevant project context.

With an appropriate model and tools, an assistant can build an application, check files, run tests, prepare a project costing, research a choice or produce a polished handover. You decide the scope and access; important results still need review.

## Your models, your setup

Connect OpenAI-compatible services, native Anthropic or Google profiles, supported Azure routes, or compatible local/self-hosted servers. Save multiple profiles and choose models for different Rooms, workspaces and capabilities. One ready Chat profile is enough to start; Utility and media services are optional.

LocalFirst-AI does not bundle model weights, server software, provider accounts or credits. Compatibility depends on the model, API route, device and tools involved.

## Work together, without losing the project

Opt into Supervisor workspaces to coordinate focused specialists. Review the assignment tree, open workers' workspaces, inspect findings and let the Supervisor bring the outcome together. Nested teams are available when enabled. Shared team, request, concurrency and time limits help bound a job; they are not monetary spending caps.

Active and History views keep ongoing work separate from finished assignments. Work can continue across navigation within the running app. Closing the app or mobile suspension can interrupt it; unfinished actions are not silently replayed. Stop does not undo actions already completed.

## Keep your methods ready

Create or import text-based Skills for writing styles, research methods, coding conventions and checklists. Review immutable versions, choose when guidance applies, request a Skill for one message and capture a useful workflow as an editable draft. Make a Skill available globally to reuse its existing identity across projects.

Skills guide the model; they do not grant permissions, run bundled scripts or turn an untrusted workflow into a safe one. Review imported guidance and remove confidential details before sharing.

## From information to deliverables

- Read supported attachments and local documents; use configured OCR for scans where available.
- Create editable Word documents, spreadsheets, presentations and styled PDFs.
- Present information as inline charts, comparisons, metrics, timelines, heatmaps and process flows; copy or save visuals as images.
- Research current information through separately configured web search and grounding, retaining sources with findings.
- Configure image generation/editing, supported video services, speech, transcription and realtime interaction when useful.
- Export saved conversation text and original artifacts without asking the model to recreate them.
- Back up supported application data; restore replaces the archive's covered data rather than merging it. Expect to re-enter secure credentials.

Tools and format support vary by device and configuration. Styled PDF generation on Windows uses installed Edge or Chrome. Windows and Android do not have identical capabilities.

## A calmer place to work

The **Sky** light theme uses airy pale-blue backgrounds, clean white surfaces and deep-blue actions. **Midnight** pairs soft sky-blue accents with quiet navy surfaces. System, light and dark appearance settings remain available; the new visuals do not change your saved projects or provider setup.

## Platforms and downloads

Windows x64 is the primary desktop experience, with installer and portable package options. Android supports sideloading on Android 7.0+ arm64-v8a devices and x86_64 emulators, with more limited local tooling. Public Web, macOS and iOS binaries are not included in this release plan.

Download only assets attached to the [official release](https://github.com/daemosofchaos/localfirst-ai-preview/releases). The planned V1.0 asset names are:

- `LocalFirst-AI-1.0.0-win-x64-setup.exe`
- `LocalFirst-AI-1.0.0-win-x64-portable.zip`
- `LocalFirst-AI-1.0.0-android.apk`
- `LocalFirst-AI-1.0.0-android-preview.zip`
- `LocalFirst-AI-1.0.0-SHA256SUMS.txt`

Verify SHA-256 against the manifest attached to the same release before installing. [Getting started](GETTING-STARTED.md) explains installation and model setup.

## Privacy, access and limitations

Local-first is not automatically offline. Connected services can receive the context, files and tool results needed for a workflow. File tools have full access by default within operating-system permissions; optional directory-access requests do not sandbox processes, plugins or other software. Select limited access, use non-sensitive data while learning and keep backups.

Model output may be inaccurate, incomplete or unsafe. Live text updates require a supported connection; files, Skills and selected-text context remain next-message inputs. Large files can take time to prepare, and mobile suspension can interrupt work. Review consequential actions and do not rely on unattended operation for high-stakes decisions.
